# Aangan Interiors (React + Vite)

## Run locally
1. Install Node.js if it is not already installed.
2. Open this folder in VS Code.
3. Open the terminal in VS Code.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL Vite prints in your terminal.

## Main files
- `src/App.jsx`: assembles all page components and scroll reveal animation.
- `src/components/Header.jsx`: responsive navigation.
- `src/components/Hero.jsx`: hero section.
- `src/components/Services.jsx`: services cards.
- `src/components/Gallery.jsx`: gallery banner.
- `src/components/Projects.jsx`: selected projects.
- `src/components/Philosophy.jsx`: brand philosophy section.
- `src/components/Contact.jsx`: contact calls to action.
- `src/components/Footer.jsx`: footer.
- `src/styles.css`: all styling and responsive breakpoints.

## Before publishing
Replace the sample email `hello@aanganinteriors.in` and the WhatsApp placeholder `91XXXXXXXXXX` with your actual contact details. Images and Google Fonts are loaded from online URLs, so an internet connection is needed for them to appear.
